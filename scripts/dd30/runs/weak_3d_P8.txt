# Weak scaling on the channels problem (ex6, coefficient channels, kappa_channel 1e6, background 1) with 8 ranks:
# 8^3 cells, refined twice, i.e. 16^3 elements per subdomain, at velocities 1 and 100 (see channels_3d.txt).
# The channels scale with the subdomains (8 per slice, width 0.0625: 2 elements wide, 4 apart, as with 64 ranks and
# the defaults of ex6.ini), so that every subdomain sees the same local problem; with the channels fixed in space,
# 8 subdomains had ~100 channels each, more than 40 eigenvectors can capture (all methods ~180 iterations).
# GMRES may take up to 1000 iterations, so that the one-level methods can show their growth with the number of
# subdomains. Submitted with 16 ranks per node (8 ranks: CORES_PER_RANK=4, so that the ranks share the memory
# bandwidth as on the other nodes).
